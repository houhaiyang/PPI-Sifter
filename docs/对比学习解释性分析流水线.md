## 各脚本详细注释卡

### 阶段 0 — 离线特征提取

#### `scripts/emb/`（目录整体）

| 项目 | 说明 |
| :-- | :-- |
| **作用** | 离线用 ESM-C 提取所有蛋白的 residue-level embeddings，保存为 HDF5 |
| **输入** | FASTA 文件（蛋白序列），YAML 中 `data.hdf5_path` |
| **输出** | `data/BIOGRID/embeddings/embeddings.h5`，每条蛋白一个 `L × d` 张量 |
| **处理逻辑** | 逐蛋白批量编码，写入 HDF5，支持断点续写；ESM-C 冻结，不参与梯度 |
| **执行时机** | 训练前**一次性运行**，后续所有阶段都复用此 H5 文件 |
| **执行命令** | `python scripts/emb/<提取脚本>.py` |


***

### 阶段 1 — 训练

#### `scripts/train/train.py` ✅ **主入口**

| 项目 | 说明 |
| :-- | :-- |
| **作用** | 端到端训练主脚本，含对比学习头、early stopping、checkpoint 保存 |
| **输入** | `configs/default.yaml`（或 `contrast.yaml`），HDF5 embeddings，pairs CSV |
| **输出** | `outputs/checkpoints/best_auprc.pt`（含 model + contrast_head state_dict） |
| **处理逻辑** | ① 读 YAML 构建 PPISifter + LayerwiseContrastHead；② 每个 batch 同时算 cls loss + contrast loss + attn reg；③ loss dict 各分项可接 TensorBoard；④ `contrast.enabled=false` 时自动退化为原版 |
| **关键开关** | `configs/default.yaml` → `contrast.enabled`, `contrast.active_layers`, `contrast.lambda_contrast` |
| **执行命令** | `python scripts/train/train.py` |


***

### 阶段 2 — 评估

#### `scripts/train/eval.py` ✅ **保留**

| 项目 | 说明 |
| :-- | :-- |
| **作用** | 在 val / test split 上跑标准评估，输出 AUROC、AUPRC、F1、PR 曲线 |
| **输入** | `outputs/checkpoints/best_auprc.pt`，test pairs CSV，HDF5 |
| **输出** | `outputs/preds/eval_results.json`，PR 曲线图 |
| **处理逻辑** | 加载 model（不需要加载 contrast_head），批量前向，汇总 metrics；注意原 `eval.py` 的 `loss_fn.forward()` 返回值现在是 dict，需对接 `loss_dict["total"]` |
| **注意** | **需小改**：`PPILoss.forward()` 改造后返回 dict，eval.py 里若有 `loss = loss_fn(...)` 需改为 `loss = loss_fn(...)["total"]` |
| **执行命令** | `python scripts/train/eval.py` |


***

### 阶段 3 — 推理导出

#### `scripts/train/infer.py` ✅ **保留**

| 项目 | 说明 |
| :-- | :-- |
| **作用** | 对任意蛋白对列表批量打分，导出 pair-level prob + 可选 layer_reprs |
| **输入** | `outputs/checkpoints/best_auprc.pt`，待推理 pairs CSV，HDF5 |
| **输出** | `outputs/preds/predictions.csv`（含 prob），可选 `layer_reprs_*.pt` |
| **处理逻辑** | 调用 `model.forward(return_layer_reprs=True)` 导出中间层表示；若 `configs.infer.export_layer_reprs=true` 则保存为 `.pt` 供下游分析 |
| **注意** | **需小改**：在 `model.forward()` 调用处增加 `return_layer_reprs=cfg["infer"].get("export_layer_reprs", False)` |
| **执行命令** | `python scripts/train/infer.py` |


***

### 阶段 4 — 对比机制分析（路线 E 核心）

#### `scripts/interpretability/run_contrast_analysis.py` ✅ **新增，核心**

| 项目 | 说明 |
| :-- | :-- |
| **作用** | 一键运行全部对比学习式机制分析，回答"哪层学到 partner-aware pattern" |
| **输入** | `outputs/checkpoints/best_auprc.pt`，test split HDF5 + pairs |
| **输出** | `outputs/analysis/layer_separability.json`，`attention_stats_profile.json`，`partner_shift.json` |
| **处理逻辑** | ① 收集各层 pair_repr 和 attn_stats；② layer separability：训练线性 probe，报告各层 AUROC；③ entropy gap：正负样本各层 attention entropy 均值差；④ partner shift：正负样本表示欧氏距离偏移 |
| **执行命令** | `python scripts/interpretability/run_contrast_analysis.py` |


***

## 三处必须手动小改的位置

执行前需确认以下三处改动（原有脚本，改动量很小）：

**① `scripts/train/eval.py` 第 ~50 行附近**

```python
# 原版
loss = loss_fn(logits, targets, attn_ab, attn_ba)

# 改为
loss = loss_fn(logits, targets, attn_ab, attn_ba)["total"]
```

**② `scripts/train/infer.py` `model.forward()` 调用处**

```python
# 原版
out = model(emb_a, emb_b, mask_a, mask_b, return_attention=True)

# 改为
out = model(emb_a, emb_b, mask_a, mask_b,
            return_attention=True,
            return_layer_reprs=cfg["infer"].get("export_layer_reprs", False))
```

**③ `ppisifter/interpret.py` 中若有调用 `PPILoss.forward()`**

```python
# 同样改为取 ["total"]
loss = loss_fn(...)["total"]
```
