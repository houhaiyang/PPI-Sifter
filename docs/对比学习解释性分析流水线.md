## 一、流水线定位

本文档描述 PPI-Sifter 项目中，对比学习解释性分析的**完整执行流水线**。流水线目标是：在模型训练完成后，通过离线分析量化回答以下三个问题：

1. **哪一层**的 cross-attention 中间表示对正负样本具有最强的可分性？
2. 模型是否以 **partner-conditioned 方式**编码蛋白信息（即同一蛋白面对不同 partner 时表示发生定向偏移）？
3. 正负样本在各层的 **attention 分布**是否具有统计上显著的结构性差异？

这三个分析分别对应流水线中的 **Layer Separability Analysis**、**Partner Shift Analysis** 和 **Attention Entropy Gap Profile**，均属于推理后的离线分析，与训练主干完全解耦。

## 三、各阶段详细说明

### 阶段 0 — 离线特征提取

#### `scripts/emb/extract_esmc.py`

| 项目 | 说明 |
|---|---|
| **作用** | 离线使用冻结 ESM-C 提取所有蛋白的 residue-level embeddings，保存为 HDF5 |
| **输入** | FASTA 文件（蛋白序列列表）；`configs/default.yaml` 中 `data.hdf5_path` |
| **输出** | `data/BIOGRID/embeddings/embeddings.h5`；每条蛋白保存一个 `L × 1152` float16 张量及 `length` 标量 |
| **处理逻辑** | 逐蛋白批量编码；支持断点续写（已存在的 key 跳过）；ESM-C 冻结，不参与梯度 |
| **执行时机** | 训练前**一次性**运行；后续所有阶段均复用此 HDF5 |
| **执行命令** | `python scripts/emb/extract_esmc.py --config configs/default.yaml` |
| **注意事项** | 序列长度超过 1024 按截断策略处理；ESM-C 权重路径在 YAML 中配置 |

### 阶段 1 — 模型训练

#### `train/train.py` ✅ 主入口

| 项目 | 说明 |
|---|---|
| **作用** | 端到端训练主脚本；同时训练 PPISifter 主干 + LayerwiseContrastHead |

| **关键开关** | `contrast.enabled`，`contrast.active_layers`，`contrast.lambda_contrast` |
| **执行命令** | `python train/train.py --config configs/default.yaml` |

#### 4.1 分析模块 A：Layer Separability Analysis

**所在函数**：`analysis.compute_layer_separability()`

**算法流程：**

```
for each layer l in [1..N]:
    X_l = load pair_repr_l.pt        # shape: [n_samples, 2d]
    y   = load predictions.csv["label"]

    1. 训练 LogisticRegression（max_iter=200, C=1.0, solver=lbfgs）
       → probe_auroc_l, probe_auprc_l

    2. 计算 silhouette_score(X_l, y)
       → silhouette_l

    3. 计算 davies_bouldin_score(X_l, y)
       → db_index_l

输出 layer_separability.json：
{
  "layer_1": {"probe_auroc": 0.xx, "probe_auprc": 0.xx, "silhouette": 0.xx, "db_index": 0.xx},
  "layer_2": {...},
  ...
}
```

**解读规则：**

- `probe_auroc` 接近最终分类头 AUROC → 该层已充分编码 partner-aware pattern；
- `silhouette` 越高 → 正负样本聚类越紧致分离；
- `db_index` 越低 → 类内紧、类间散，更好的可分性。

---

#### 4.2 分析模块 B：Partner Shift Analysis

**所在函数**：`analysis.compute_partner_shift()`

**算法流程：**

```
对 test set 中每一个 anchor protein A：
    B_pos = 真实 partner（label=1）
    B_neg = 随机负样本 partner（label=0）
    B_hard = hard negative（负采样时标注为 hard）

    for each layer l:
        repr_pos = Pool(H_A^l(A, B_pos))   # 从 pair_repr_l 中提取 A 侧表示
        repr_neg = Pool(H_A^l(A, B_neg))
        delta_pos_neg = ||repr_pos - repr_neg||_2

    shift_profile[anchor_id] = {layer: delta}

汇总：
    mean_shift_per_layer = mean over anchors
    std_shift_per_layer  = std over anchors
```

**输出格式：**

```json
{
  "layer_1": {"mean_shift": 0.xx, "std_shift": 0.xx},
  "layer_2": {"mean_shift": 0.xx, "std_shift": 0.xx}
}
```

**解读规则：**

- `mean_shift` 随层数增加应有明显增长趋势 → 表明 partner-aware 信息在深层逐步建立；
- 若所有层偏移均匀且小 → 模型可能依赖输入 embedding 本身而非 cross-attention 交互。

---

#### 4.3 分析模块 C：Attention Entropy Gap Profile

**所在函数**：`analysis.compute_entropy_gap()`

**算法流程：**

```
for each layer l:
    attn_stats = load attn_stats_l.json

    H_pos_l = mean attention row entropy for positive samples (label=1)
    H_neg_l = mean attention row entropy for negative samples (label=0)

    entropy_gap_l = H_pos_l - H_neg_l

    附加统计：
    - head_var_pos, head_var_neg
    - sym_error_pos, sym_error_neg
    - top-k token stability（跨 seed 一致性）
```

**输出格式：**

```json
{
  "layer_1": {
    "entropy_pos": 2.xx,
    "entropy_neg": 3.xx,
    "entropy_gap": -1.xx,
    "head_var_pos": 0.xx,
    "head_var_neg": 0.xx,
    "sym_error_pos": 0.xx,
    "sym_error_neg": 0.xx
  },
  ...
}
```

**解读规则：**

- `entropy_gap < 0`（正样本 entropy 更低）→ 正样本注意力更聚焦，符合生物学预期；
- `head_var` 正样本更低 → 各 head 注意力方向更一致；
- `sym_error` 正样本更低 → 双向交互更对称稳定。

## 六、三处必须手动适配的代码改动

在新建项目中，如果从旧版代码迁移，以下三处需手动确认：

### ① `evaluate/eval.py`（loss dict 对接）

```python
# 若旧版写法：
loss = loss_fn(logits, targets, attn_ab, attn_ba)

# 新版 PPILoss.forward() 返回 dict，改为：
loss = loss_fn(logits, targets, attn_ab, attn_ba)["total"]
```

### ② `inference/infer.py`（return_layer_reprs 开关）

```python
# 旧版：
out = model(emb_a, emb_b, mask_a, mask_b, return_attention=True)

# 新版（增加 return_layer_reprs 参数）：
out = model(
    emb_a, emb_b, mask_a, mask_b,
    return_attention=True,
    return_layer_reprs=cfg["infer"].get("export_layer_reprs", False)
)
```

### ③ `model/interpret.py`（若存在，loss dict 对接）

```python
# 若文件中有 PPILoss.forward() 调用：
loss = loss_fn(...)["total"]
```
